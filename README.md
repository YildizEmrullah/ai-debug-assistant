# AI Debug Assistant

Mini-RAG tabanlı yapay zeka destekli hata ayıklama sistemi.

## Özellikler
- Regex tabanlı hata analizi
- TF-IDF mini-RAG pipeline
- Cosine similarity retrieval
- SQLite analiz geçmişi
- Streamlit arayüzü
- Demo hata örnekleri

## Kullanılan Teknolojiler
- Python
- Streamlit
- SQLite
- Scikit-learn
- TF-IDF
- Regex

## Çalıştırma

```bash
pip install -r requirements.txt
streamlit run app.py
